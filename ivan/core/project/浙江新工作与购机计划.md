# 浙江新工作与购机计划

## 背景
- 2025年换新工作，方向：Java后端（Spring）
- 现有：台式机（打游戏用）+ 老联想小新（5-6年，该换）
- 需求：便携开发本，能跑 WSL2/Docker/IDE，装 Linux

## 购机方案：ThinkPad T14 二手

### 推荐配置
- **型号**：T14 Gen 2（2021）或 Gen 3（2022）
- **CPU**：i7-1165G7（Gen 2）或 i7-1255U（Gen 3）
- **内存**：32G（必须，WSL2+Docker 质变）
- **硬盘**：1T SSD
- **预算**：¥4,500-6,500（二手闲鱼）

### 价格参考
| 机型 | 配置 | 二手价 |
|------|------|--------|
| T14 Gen 2 i7+32G+1T | | ¥4,500-5,500 |
| T14 Gen 3 i7+32G+1T | | ¥6,000-7,500 |

### 为什么选 ThinkPad
1. Linux 兼容性最好（内核有 thinkpad_acpi 模块）
2. 键盘手感顶级（敲代码舒服）
3. 可升级内存/硬盘
4. 二手性价比高
5. 优先选 Intel 版（Linux 兼容更成熟）

### 验机清单
- CPU 不是 ES/QS 工程版
- 内存真实 32G（板载8G + 插槽24G，进 BIOS 看）
- 电池循环 <300 次
- 序列号 BIOS/机身/Lenovo 官网三处对得上
- 螺丝无拆动痕迹
- 接口/屏幕/键盘/小红点全测

### 避坑
- ¥3,000 买 32G T14 大概率有问题
- 别买 ES/QS 工程版 CPU
- 别买拆过主板的
- 同城面交验机，别邮寄

## 系统安装：Arch Linux + Shorin 脚本

### 安装命令
```bash
curl -L shorin.xyz/archsetup | bash
```

### 脚本来源
- GitHub: https://github.com/SHORiN-KiWATA/shorin-arch-setup
- 这个 bootstrap 脚本只下载+执行 install.sh
- install.sh 才是真正做配置的

### 桌面环境选择
**选 Shorin Niri（shorinniri）**

选项对比：
| 选项 | 代号 | 说明 |
|------|------|------|
| Shorin Niri ⭐推荐 | shorinniri | 作者完整 dotfiles，开箱即用 |
| Minimal Niri | minimalniri | 极简版，自己配 |
| Shorin DMS Niri | shorindmsgit | niri + DMS quickshell |
| End4 illogical-impulse | end4 | 最流行的 quickshell 配置 |
| DMS DankMaterialShell | dms | Material 3 风格 quickshell |

### 可选模块
- ✅ Hardware Drivers（GPU 驱动，必选）
- 可选：Shorin Arch Repository、IWD WiFi、双系统修复、GRUB 主题、常用软件

### 安装后原则
1. **装一次就够，别追作者配置更新**
2. 只跑 `paru -Syu` 更新系统软件
3. `paru -Syu` 不碰 ~/.config/ 里的配置
4. 想同步作者配置才手动跑 `shorinniri init`（一般不需要）
